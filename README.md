# 🏋️ SVS Fitness - Full-Stack Gym Member Portal & Management Hub

A comprehensive, production-ready **SVS Fitness Gym Portal** built following the **Full Web Developer Path**:

```
[ Frontend ]
HTML5  ──►  CSS3 (Dark Glassmorphism)  ──►  JavaScript (ES6+)  ──►  React / Next.js

[ Backend ]
Node.js  ──►  Express.js  ──►  RESTful API Endpoints

[ Database ]
MySQL Relational Schema (Users, Roles, Subscriptions, Bookings, Workouts, Diet Logs)
```

---

## 🌟 Key Features Included

1. **Dual Role System (Member vs Owner/Admin)**:
   - **Member View**: Active streak, digital turnstile QR pass, workout logger, class booking, diet macros, BMI & BMR health calculator.
   - **Owner View**: Gym overview & monthly revenue, active attendance, member directory management, class scheduler, API & database docs.

2. **Workout Planner & Logger**:
   - Categorized by muscle group (Chest, Back, Legs, Shoulders, Arms, Core) with automatic PR detection.

3. **Fitness Class & Trainer Booking**:
   - Strength, HIIT, Yoga, and Spinning classes with real-time spot reservations.

4. **Diet, Nutrition & Calorie Tracker**:
   - Real-time macro progress bars (Protein, Carbs, Fats, Calories).

---

## 🚀 How to Run Locally

### 1. View Frontend
Open `frontend/index.html` directly in any web browser.

### 2. Run Node.js / Express Backend
```bash
cd backend
npm install
npm start
```
Server runs on `http://localhost:5000`.

### 3. Setup MySQL Database
Import `database/schema.sql` into MySQL Workbench.
